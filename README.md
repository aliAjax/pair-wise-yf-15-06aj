# hxyfront-62003 法医昆虫学样本记录 · 补批次鉴定封存

源提示词编号：5

记录采样地点、环境温度、尸体暴露阶段、昆虫种类、发育阶段、采样时间、保存方式和鉴定备注，
支持样本批次列表、发育阶段筛选、温度记录图、案件样本关联页和单个样本详情卡片，
并实现「补批次鉴定封存」的完整工作流。

## 封存规则

1. **随批次提交的前提**：昆虫种类、发育阶段、鉴定结论、保存方式四项齐全；缺一即「待鉴定」，不可提交。
2. **封存冲突检测**：同一案件内，采样地点相同且采样时间区间重叠（含端点相接）的样本不得同时封存。
   - 冲突样本退回「待复核」，无冲突样本正常封存；
   - 若批次样本全部冲突，则不执行封存，批次保持「待封存」；
   - 原批次和已有封存记录始终不变。
3. **封存样本复核退回**：样本转待复核，所在批次立即解封并暂停导出（批内其他封存样本不受影响）。
4. **处理后重查**：修改待复核样本后执行「重查采样时间」，与全部已封存样本重新比对：
   - 曾封存批次：通过即恢复封存；批内无其他待复核样本时，批次恢复「已封存」并可导出；
   - 从未封存批次：通过即回到批次待封存，再次封存成功后才进入封存。
5. **本地持久化**：批次列表、案件关联、样本与温度图数据共用一份状态，通过 `localStorage` 保存，刷新后仍在；
   页头「恢复演示数据」可一键重置。

## 页面

- **批次封存**：批次列表（待封存 / 已封存 / 已解封·暂停导出）、可提交样本勾选提交、封存结果报告（冲突对依据）、复核退回与重查、封存清单 CSV 导出（仅已封存批次可导出）。
- **样本工作台**：新增/编辑样本、发育阶段筛选、案件筛选、鉴定四项齐全度提示。
- **案件样本关联**：按案件分组的采样时间线、关联批次与封存状态。
- **温度记录图**：纯 SVG 折线图，按采样时间排列，点颜色区分发育阶段，支持阶段与案件筛选，悬停查看明细。
