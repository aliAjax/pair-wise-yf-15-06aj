# hxyfront-62003 法医昆虫学样本记录

源提示词编号：5

法医昆虫学样本记录前端工具，记录采样地点、环境温度、尸体暴露阶段、昆虫种类、发育阶段、采样时间、保存方式和鉴定备注。页面包含样本批次列表、发育阶段筛选、温度记录图、案件样本关联页和单个样本详情卡片。

## 批次鉴定封存流程

- **齐全才能提交**：样本的昆虫种类、发育阶段、鉴定结论、保存方式四项齐全后，所在批次才能提交封存；不齐全时提交被拦截并提示缺项。
- **冲突退回**：同一案件内采样时间重叠且地点相同的样本不得同时封存。提交时检出冲突的样本退回「待复核」，原批次与封存记录保持不变。
- **复核解封**：已封存样本被复核退回时，所在批次立即解封并暂停导出；处理完成后重查采样时间，通过才恢复封存、恢复导出。
- **封存记录**：批次的封存 / 解封 / 恢复封存全程追加记录，不回改历史。
- **本地持久化**：批次列表、案件关联、温度图共享同一份状态并实时同步，数据保存于 localStorage，刷新后仍在。可用页面右上角「重置演示数据」恢复初始种子数据。
